A few things to know.

Is this an official CTS service?

CTS Departures is an independent project by JibStudios. It uses departure information from Strasbourg’s CTS network and is not affiliated with or endorsed by CTS.

Do I need a pixel display?

The departure board works in a browser on your phone, tablet or computer. The optional Divoom Pixoo64 adds a dedicated pixel display for your home or desk.

How do I get started?

The project is free and open source. Download a release and follow the setup guide on GitHub. It needs an initial setup before you can display your own stops. Read the getting-started guide.
